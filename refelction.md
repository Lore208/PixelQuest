Wat is het verschil tussen Watch, Star en Fork?
watch: Is om genotificeerd te worden van je repository als je eraan meedoe of gementioned word. Ook voor activiteit die gebeurt in je repo.
star: Kan je mensen een ster geven.
Fork: Een copy maken van je repo zodat als je iets wilt testen het niet op de main repo komt.

Waarom zijn Issues nuttig in een softwareproject? 
Zo kan je aan een bepaalde taak werken op een feature branch waar dat er uitleg in staat gegeven. 

Hoe helpen Labels en Milestones bij projectbeheer?
Labels tonen makkelijker aan wat dat er gebeurt moet worden in een issue.
Milestones toont aan hoe ver je project al zit en welke issues er gedaan moeten worden.

Waarom controleer je een Pull Request voor je die merge?
Er kunnen overal nog fouten optreden zoals in de code die niet gedaan is of niet de conventies volgt. Zo kunnen zij dat noh aanpassen voor je de main of dev branch vervuild. 

Wat is het verschil tussen Raw, History en Blame?
Raw toont hoe het eruit ziet in code.
History toont aan welke commits er allemaal gedaan werden.
Blame toont aan welke stuk code er aangepast is in welke commit.

Wanneer zou je een Wiki gebruiken in plaats van een README?
Omdat een wiki duidelijker is en makkelijker te vinden is dan README. ook staat alle info daar netter en op verschillende pages dus het is makkelijker om terug te vinden.
